# Security Policy

## Supported versions

The latest `main` branch is supported during the 0.x development line.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Contact the maintainer privately through the security contact listed on the GitHub profile, including reproduction steps, affected files, impact, and a safe mitigation if known. Do not include live credentials or private repository contents.

Shipwright is designed not to execute inspected repository code or upload source files. Reports involving path traversal, unintended command execution, secret exposure, unsafe parsing, or dependency compromise receive priority.
